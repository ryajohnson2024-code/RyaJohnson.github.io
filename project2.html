Project Description

In this project, I used Python Turtle Graphics to create a sunny beach scene. The drawing includes ocean water, sand, a bright sun, a palm tree, and a sandcastle. I used custom functions to draw shapes and combine them into a complete picture.

What I Learned

This project helped me learn how to use functions, loops, and Turtle Graphics to create a larger drawing. I learned how to break a project into smaller parts and combine simple shapes to create a complete scene.
