Project 2 - Turtle Graphics Beach Scene

Created by Rya Johnson

This project was created using Python Turtle Graphics. The program draws a sunny beach scene featuring:

  • Blue ocean water
  • Sandy beach
  • Bright yellow sun
  • Palm tree
  • Sandcastle

I used custom functions to draw shapes such as rectangles, circles, triangles, polygons, and curves to build the scene.
