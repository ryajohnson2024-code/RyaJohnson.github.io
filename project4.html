Project 4 - Pride and Prejudice Text Analysis

Overview

This project analyzes the text of Jane Austen's Pride and Prejudice using Python. The program downloads the novel, calculates statistics, counts word frequencies, and identifies the most common words throughout the text.

Project Goals

  • Download and process text from Project Gutenberg
  • Calculate character, line, and word counts
  • Count word frequencies
  • Identify common patterns in the novel
  • Explore natural language processing techniques

Tools and Skills Used

  • Python
  • Functions
  • Dictionaries
  • Text Processing
  • Data Analysis
  • spaCy Natural Language Processing

Key Findings

Basic word counts showed that common words such as "the", "of", and "and" appeared most often. After using spaCy to remove filler words and group similar words together, more meaningful words appeared. This made it easier to identify important characters, themes, and relationships within the novel.

Top 15 Most Frequent Words

After processing the text with spaCy and removing common filler words, these were the 15 most frequent words found in Pride and Prejudice.

  • Elizabeth — 639
  • Darcy — 428
  • Say — 426
  • Know — 394
  • Mrs. — 354
  • Bennet — 348
  • Think — 346
  • Miss — 319
  • Bingley — 315
  • Jane — 303
  • Sister — 292
  • Lady — 280
  • Come — 268
  • Good — 248
  • See — 245

Reflection

Through this project, I learned how computers can analyze large amounts of text and identify patterns. I gained experience using dictionaries, functions, and natural language processing tools to better understand written data.
