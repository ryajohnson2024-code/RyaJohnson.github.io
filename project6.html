Project 6 - Netflix Data Analysis

Overview

This project explores Netflix movie data using Python, pandas, matplotlib, and seaborn. The goal was to determine which age group had the most movies released on Netflix between 2000 and 2021.

Research Question

Which age group had the most movies released on Netflix from 2000 to 2021?

Tools and Skills Used

  • Python
  • Pandas
  • Matplotlib
  • Seaborn
  • Data Visualization
  • Data Analysis

Findings

The analysis showed that movies targeted toward adults made up the largest portion of Netflix releases. Teen-focused movies ranked second, while movies for children were released less frequently.

Visualizations Created

  • Pie Chart showing movie proportions by age group
  • Bar Chart comparing the number of movies in each age group

Reflection

This project helped me learn how to clean, analyze, and visualize real-world data. I gained experience working with datasets and using charts to answer meaningful questions.
